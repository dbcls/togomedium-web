# TogoMedium 依存更新候補

調査日: 2026-09-18

## 後続の記録と現在値（2026-09-27追記）

以下は調査時点の候補一覧。採用・検証の結果は `docs/reports/2026-09-18-dependency-update-results.md` を参照する。現在の依存宣言は各 `package.json`、解決バージョンは `pnpm-lock.yaml`、Node.jsとpnpmは `mise.toml` で確認する。この一覧の「現在」「最新候補」を、そのまま現行環境や検証済みの推奨値として使わない。

## 調査範囲

`mise exec -- pnpm outdated -r --format json` と `pnpm view` によるnpmレジストリ照合。ルートと全6パッケージの直接依存を対象にした。現在値はインストール済みの解決バージョン、最新値は調査時点の `latest` タグであり、互換性を検証済みの採用バージョンではない。

更新候補は58種類。うち9種類は廃止予定の `@packages/api-doc` 専用で、現行パッケージ側の候補は49種類。推移的依存の全件更新リストではなく、実際のlockfile更新で変更される間接依存は別途レビューする。

この調査では依存ファイル・インストール状態を変更していない。TogoStanza alpha.2への更新とV4移行の未コミット変更は保持している。

## 推奨する更新単位

1. **実行環境とCI**: Node 24系の更新、Node型定義の世代整合、CIとmiseの一致を確認する。pnpmのメジャー更新はlockfileへの影響を分けて検証する。
2. **ビルド・テスト**: Vite 8、Reactプラグイン、Vitest 5、jsdom、Storybookを関連する組として更新する。Web・Stanza・Storybookのビルドとブラウザ表示を確認する。
3. **型・品質管理**: TypeScript、Oxlint、oxlint-tsgolint、Oxfmtをまとめて整合確認する。Oxfmtによる広範囲の整形差分は機能変更と分ける。
4. **UI・状態管理**: React関連の同一メジャー更新、MUI、Jotaiを段階的に進める。MUIとJotaiは独立した移行単位にする。
5. **データ取得・API・その他**: TanStack各系統、ZodとOpenAPI変換、その他のユーティリティを更新する。
6. **旧APIドキュメント**: 廃止予定パッケージを維持するか確認したうえで、必要なら別枠で更新する。

## 先に押さえる制約

- Vite 8.3.0はNode `^20.19.0 || >=22.12.0`、Vitest 5.0.1は `^22.12.0 || ^24.0.0 || >=26.0.0` を要求する。現在のNode 24.5.0は両方の条件を満たす。
- `@vitejs/plugin-react` 6.1.1はVite `^8.0.0` を要求する。単独で先行更新しない。
- `@vitejs/plugin-react-swc` 4.3.3と `@storybook/react-vite` 10.6.0は、peerDependenciesにVite 8を含む。
- Vite 8はRolldown/Oxcへ移行する。React/EmotionのJSX、旧APIドキュメント用Viteプラグインを含めて確認する。公式移行ガイド: https://vite.dev/guide/migration
- Vitestの設定・mock・jsdomテストを確認する。公式移行ガイド: https://vitest.dev/guide/migration/
- `@emotion/babel-preset-css-prop` の最新11.12.0も `@babel/core: ^7.0.0` を要求する。Babel 8.0.5は現構成のまま一括適用しない。プリセット等が実際に必要かを確認し、維持するならBabel 7系の範囲で検討する。
- `@asteasolutions/zod-to-openapi` 9.1.0はZod `^4.0.0` を要求する。現行のZod世代とは整合するが、生成されるAPIスキーマの差分検証は必要。
- TanStack Router本体・Devtools・Pluginの最新番号は異なる。同じ番号に機械的に揃えず、公開済みの組み合わせとpeerDependenciesを確認する。
- `resolutions.esbuild = 0.24.0` は固定理由を調べて見直す。Vite 8.3.0のesbuild peer範囲は `^0.27.0 || ^0.28.0` であり、固定の必要性・適用先を確認する。
- `@packages/api-doc` のTypeSpec系8依存は `latest` 指定。更新を行うなら、再現可能なバージョン指定への変更も検討する。
- 0.xの更新は、小数点以下の更新でも互換性変更があり得る。特にOxfmt・Scalar・yohak-toolsは個別に差分確認する。
